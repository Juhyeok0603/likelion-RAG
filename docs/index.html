BEFORE RAG

먼저, 일반 LLM은 어떻게 답할까?

LLM은 질문을 잘게 나눈 뒤, 학습하면서 익힌 패턴을 바탕으로 다음에 올 말을 하나씩 예측해 답변을 만듭니다.

01 · INPUT질문 입력“이번 과제 마감은 언제야?”
→
02 · TOKEN토큰으로 분리문장을 모델이 처리할 작은 단위로 나눔
→
03 · PREDICT다음 토큰 예측학습된 패턴과 현재 문맥을 사용
→
04 · OUTPUT답변 생성예측을 반복해 문장을 완성
중요한 한계일반 LLM은 지금 우리 컴퓨터의 공지 파일이나 Qdrant를 자동으로 읽지 않습니다. 학습하지 않은 최신 동아리 정보는 모르거나 그럴듯하게 추측할 수 있습니다.
일반 LLM질문 → 학습된 패턴 → 답변

모델 내부에 이미 학습된 정보와 현재 대화만 사용합니다. 우리 동아리의 최신 공지는 알 수 없습니다.

RAG질문 → 외부 문서 검색 → 문서와 질문 → 답변

답변 전에 우리가 저장한 자료를 찾아 LLM에 함께 건넵니다. 모델을 다시 학습하지 않아도 새 자료를 참고할 수 있습니다.

RAGRetrieval-Augmented Generation

모델이 데이터의 특징이나 의미가 가까이 모이도록 만든 벡터입니다. 의미를 보존하는 벡터화라고 볼 수 있습니다.

COMPARE

벡터 검색

질문 벡터와 문서 벡터의 방향을 비교해 의미가 가까운 문서를 찾습니다.

DIMENSION

1,024차원이란?

bge-m3가 문장 하나를 1,024개의 숫자로 표현한다는 뜻입니다. 벡터의 길이가 1,024라는 의미이지, 문장이 1,024개 단어라는 뜻은 아닙니다.

각 숫자는 모델이 학습한 의미 좌표의 일부입니다. 보통 “1번은 과제, 2번은 날짜”처럼 사람이 차원 하나씩 해석하지 않습니다.

-0.03290.0215-0.01610.0084…0.0412총 1,024개
같은 모델문서와 질문은 모두 bge-m3로 임베딩해야 같은 공간에서 비교할 수 있습니다.
같은 차원Qdrant 컬렉션에 저장되는 벡터는 모두 1,024차원이어야 합니다.
유사도 ≠ 확률0.55가 55% 정답이라는 뜻은 아닙니다. 질문과 자료를 바꿔 기준을 직접 관찰해야 합니다.
